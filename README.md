# Manga SMB Suite - Docker & CasaOS Web UI

A modern, high-performance web interface designed for **CasaOS** and **Docker** on Ubuntu Linux to manage, verify, convert, and synchronize large Manga / Manhwa collections over SMB shares.

Taking direct inspiration and design cues from **SyncToHDD**, this suite transforms standalone Python scripts and maintenance routines into an automated, queue-managed service with live terminal log streaming, dry-run safety modals, and an interactive reports center.

---

## 🌟 Key Features

### 1. 🔄 Strict Sequential Execution (FIFO Queue)
- **1-at-a-time execution**: Python scripts never conflict or saturate your I/O; jobs execute strictly one after the other.
- **Queue Management**: Enqueue multiple scripts, reorder items up/down, remove pending jobs, or cancel the currently running script gracefully.
- **Real-Time Logs**: Watch terminal output line-by-line via Server-Sent Events (SSE) directly in your browser with auto-scroll and manual pause controls.

### 2. 🛡️ Interactive Dry Run Modal
- Every run action triggers a confirmation modal prompting you to choose between:
  - **Dry Run**: Preview comparisons, check duplicates, or inspect proposed file operations without writing or deleting any files on disk.
  - **Live Run**: Execute write, copy, mirror, or metadata update operations directly.
- Avoids terminal hangs: all CLI prompts (`input()`) are automatically handled in non-interactive/docker modes.

### 3. 📂 Transparent Path Translation (`Z:\` ➔ `/sg2b/Share2sgb/`)
- On Windows, your manga collection is mapped to network drive `Z:\`.
- On Linux Ubuntu server (and inside Docker), this corresponds to `/sg2b/Share2sgb/`.
- The centralized `shared.config` path resolver automatically translates paths based on OS and environment variable `MANGA_ROOT`. You can run the exact same scripts on Windows or Linux without touching hardcoded paths.

### 4. 📊 Reports Center & In-Browser Preview
- Reports generated by any script (such as Excel `.xlsx` summaries or text logs) are automatically detected and saved into `/app/data/reports`.
- **In-Browser Multi-Sheet Excel Viewer**: View generated workbooks with styled tables directly inside the UI without needing to open Microsoft Excel.
- Direct downloads and deletion management.

### 5. 🎨 Modern Dark Theme & CasaOS Native Integration
- Built with standard HTML5, CSS3, and Vanilla JavaScript for ultra-fast response times.
- Mobile-friendly responsive layout with side drawer navigation.
- Comes pre-configured with `x-casaos` metadata in `docker-compose.yml` for 1-click CasaOS App Store import.

## 🚀 CasaOS 1-Click Deployment

### Method 1: CasaOS Custom Install (Recommended)

1. Open your **CasaOS Web UI** (e.g. `http://<your-server-ip>`).
2. Click the **`+`** icon on the top right of the dashboard and select **"Install a custom app"**.
3. In the top right corner of the dialog, click **"Import"**.
4. Copy the entire contents of [`docker-compose.yml`](file:///docker-compose.yml) from this repository and paste it into the import box, then click **Submit**.
5. CasaOS will automatically populate:
   - **Docker Image**: `ghcr.io/alexlx4773h/manga-smb-docker`
   - **Tag**: `latest`
   - **App Name**: `Manga Suite`
   - **Icon**: `https://raw.githubusercontent.com/AlexLX4773H/Manga-SMB-Docker/main/assets/icon.png`
   - **Port**: `7070`
   - **Volumes**:
     - Host `/sg2b/Share2sgb` ➔ Container `/sg2b/Share2sgb`
     - Host `/DATA/AppData/manga-suite` ➔ Container `/app/data`
6. Click **Install**. CasaOS will pull the image, set up the container, and display the Manga Suite tile on your home screen!

## 🐳 Standard Docker Compose Deployment

Clone the repository to your Ubuntu server:

```bash
git clone https://github.com/AlexLX4773H/Manga-SMB-Docker.git /DATA/AppData/manga-suite-repo
cd /DATA/AppData/manga-suite-repo
```

Build and launch the container in the background:

```bash
docker compose up -d --build
```

Access the UI at:
```
http://<your-server-ip>:7070
```

To view container logs:
```bash
docker compose logs -f
```

## ⚙️ Configuration & Environment Variables

You can customize runtime behavior by creating a `config.yaml` or supplying environment variables in `docker-compose.yml`:

| Environment Variable | Default Value | Description |
| :--- | :--- | :--- |
| `MANGA_ROOT` | `/sg2b/Share2sgb` | Root directory representing Windows `Z:\` inside the container. |
| `AUTO_CONFIRM` | `1` | Automatically answers `y` to non-critical script prompts. |
| `PORT` | `7070` | HTTP port for the web application. |
| `HOST` | `0.0.0.0` | Listen IP address. |
| `APP_DEBUG` | `0` | Enable detailed debug logs (set to `1` if troubleshooting). |

### Volume Structure
- `/sg2b/Share2sgb`: Your SMB share or local storage holding the manga and manhwa folders.
- `/app/data`: Persistent application state:
  - `data/app.db`: SQLite database storing job execution history and queue state.
  - `data/logs/`: Full per-run terminal logs (`<run_id>.log`).
  - `data/reports/`: Generated Excel workbooks and text reports.
  - `data/cache/`: Pickled index caches for fast incremental duplicate scans.

You can also run Manga SMB Suite natively on Windows:

1. **Install Dependencies**:
   ```powershell
   pip install -r requirements.txt
   ```

2. **Run All Integration Tests**:
   ```powershell
   python tests/test_suite.py
   ```

3. **Start the Local Development Server**:
   ```powershell
   python -m mangarunner.main
   ```
   Open your browser at `http://localhost:7070`. On Windows, scripts will naturally access `Z:\` without needing path translations.

## 🔒 Safety & Operational Notes
- **Dry Run First**: For any batch file conversion (`Convert_to_CBZ.py`) or mirroring (`Mirror_Manga_to_CBZ_2.py`), always queue a **Dry Run** first from the UI to verify target directories and file lists before initiating a Live Run.
- **SMB Permissions**: Ensure your Docker daemon on Ubuntu has read/write permissions to `/sg2b/Share2sgb`.
